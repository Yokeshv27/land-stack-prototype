# Security policy

This repository is a local hackathon prototype, not a production land-record system. Do not upload real land documents, credentials, or production database backups.

To report a security issue, do not open a public issue with sensitive details. Contact the repository maintainer privately and include reproduction steps, impact, and a safe proof of concept.

Before production use, replace the prototype's HTTP Basic API authentication with secure session/JWT controls, add malware scanning, enforce HTTPS, move to managed PostgreSQL/PostGIS, and commission a security review.
